# 截止后预订下一天

纽约时间到当日场次截止时间后，该场次自动切换到下一自然日。当前常用设置是午餐 15:00、晚餐 21:30；后台可调整每天的截止和配送时间。午餐过后仍可选当天晚餐，午餐标签则显示明日午餐；晚餐截止后默认显示明日午餐，仍可切换明日晚餐。点餐系统不因当天截止整体关闭。

每个场次显示实际用餐日期。预订读取次日专属配送表（没有则使用常用表），仅包含符合次日日期的临时菜，保留商家设置的上下架、售罄和手动暂停规则。ASAP 指在所选用餐日尽快安排，不代表立即配送。

跨截止时间刷新保留餐袋中仍可售的菜品，批次重置为 ASAP。提交旧日期的新订单时，服务器拒绝并要求再次确认新日期，不暗中改约。已保存的草稿和凭证继续使用原日期；原请求重试仍返回原订单，避免生成重复订单。跨夏令时的截止时间按用餐日期的纽约时区计算。

后台可点击“明日预订”查看下一天订单。日期、备餐、配送和 Excel 使用订单中的用餐日期；测试订单仍和真实订单隔离。无需新增数据表或修改历史订单。
